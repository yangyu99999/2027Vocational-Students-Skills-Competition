# 驱动完善说明

## 范围与工程事实
工程：D:\Jiangsu Vocational Students Skills Competition\My_Smart_Door。
MCU：STM32F103C8（64KB Flash、20KB RAM），STM32 HAL，CubeMX配置，Keil ARMCC 5.06 update 7，裸机，无FreeRTOS。
主程序Core/Src/main.c、ADC、现有引脚分配、时钟树、官方Drivers、Keil工程文件和原编译产物不修改。small.HMI不修改。

## 修改与原因

| 文件/模块 | 修改 | 为什么 |
| --- | --- | --- |
| gpio.c、KEY.c | PB12..15列输入上拉；PA4..7行开漏；20ms稳定消抖，一次按下只返回一次事件 | 上拉避免悬空；非扫描行释放，避免多键把推挽高低输出短接；消抖避免一次按键被算多次。并非所有按键引脚都改成输入上拉。 |
| tim.c、SERVO | TIM4_CH3/PB8改50Hz；新增Servo_SetAngle和Servo_Disable，保留旧接口 | 普通SG90按脉宽定位，不是连续正反转电机。重复调角度只更新CCR，避免HAL重复Start返回错误。 |
| usart.c、TJC | USART3改9600；采用page 0、t0.txt、t0.pco及三个FF结束字节；限制字符串长度/字符 | HMI中识别到baud=9600，原55 AA数据包与标准文本指令不匹配；限制内容避免命令损坏。 |
| BT.c/h | 检查发送/接收HAL返回值；统计缓冲满丢字节；UART1错误后恢复接收 | 原来错误可能被忽略，溢出后丢数据不可见；恢复避免通信错误后停止接收。 |
| OLED.c/h、gpio.c | SDA/SCL开漏、低速、上拉；读取并统计ACK/NACK | I2C发送1意味着释放总线，推挽会与从机ACK冲突；读取ACK能发现断线/地址错误。 |
| FLASH.c/h | 检查地址、访问宽度对齐、跨界、空指针及长度；页擦除要求1KB对齐；检查锁/解锁返回值 | 避免非法访问、越界写入或意外擦除邻页，错误能返回给调用者。 |
| RC522.c/h | SPI读取变量初始化；复位等待限制50ms并记录超时 | 避免移位使用未初始化变量；模块失联不能永久卡住程序。 |
| My_Smart_Door.ioc | 同步GPIO、PWM、USART3设置 | 避免以后CubeMX重新生成时覆盖这些配置。配置键去重，含空格的键按properties格式转义。 |

## SG90定时器计算及接口
工程采用8MHz外部晶振、PLL×9；APB1=36MHz且分频不为1，TIM4时钟按STM32F1规则×2，为72MHz。
边沿对齐、向上计数：PSC=71，计数频率72MHz/(71+1)=1MHz，每计数1us。
ARR=19999，PWM频率1MHz/(19999+1)=50Hz，周期20ms。
CCR=1000/1500/2000，对应1/1.5/2ms，占空比5%/7.5%/10%。通道CCR预装载开启。
Servo_SetAngle(&htim4,TIM_CHANNEL_3,angle)接受0..180逻辑角度，保守映射1..2ms；实际转角须标定，不能保证达到机械0/180度。首次验证卸下舵盘，测量PB8周期与脉宽后再连接机构。
Servo_Forward/Reverse/Stop分别定位到逻辑180/0/90度；Stop不是关闭PWM。关闭用Servo_Disable，关闭后不保证保持力。
当前主程序不调用PWM启动，因此配置预置1500不会自行让舵机运动。未进行示波器实测。

## 使用条件与限制
- KEY_Init在GPIO初始化后调用；KEY_Scan建议每1..5ms调用，返回1..16或0。多键不触发，稳定松开后才接受下一次；无二极管矩阵不支持可靠多键组合。原始扫描和消抖扫描不要并发调用。
- 蓝牙接收需要BT_Init；BT_GetErrorCount/BT_GetDroppedCount可观察累计错误/丢字节。当前USART1中断接收无DMA，错误恢复回调无等待循环。以后新增其他UART错误处理须合并同一个HAL回调。
- 串口屏接口当前只支持page0、t0，旧的其他页面宏已移除，避免悄悄映射到首页。控件逻辑编号0映射t0，不是屏幕真实数值ID。字符串最多64个ASCII字符，暂不支持中文。bsp_tjc_get_status只证明UART发送结果，不证明屏幕执行成功。
- HMI结构来自二进制识别，页面和控件需在陶晶驰编辑器及实屏确认。屏幕启动完成后再调用；该驱动不新增触摸按键接收业务。
- OLED_GetNackCount只记录NACK；仍保留原void接口，不会自动重试/中止整次刷新；不实现时钟拉伸。SDA/SCL应有外部上拉，内部上拉仅辅助，建议检查模块自带上拉并确认拉到3.3V。PC14/15使用低速配置。
- Flash错误地址读回全1，与已擦除数据无法区分；调用前须验证地址。GetPage无效地址返回0xFFFFFFFF。页擦除接口现在只接受页起始地址。没有预留密码存储页，调用者不能擦写固件区域；以后保存密码须先规划链接器保留区。此轮不改变Flash布局。
- RC522_ResetTimedOut在初始化/复位后读取，超时后不要继续假定读卡成功；超时依赖HAL tick，不能在中断或关闭中断时调用复位。
- EEPROM硬件I2C需外部上拉；USART2语音模块波特率仍保持115200，须按实际模块确认。本轮不凭型号猜测修改，不加入未使用的指纹、震动或语音业务。
- 主程序保持原样，驱动尚未接入业务流程，现阶段不能用这份HEX判断整机功能。
